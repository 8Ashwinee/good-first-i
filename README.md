## 🎯 What You’ll Learn
- How to **Fork** a project (make your own copy).
- How to **Clone** a project (download it to your computer).
- How to create an **Issue** (report a bug or suggest an idea).
- How to **Commit** changes (save your work).
- How to create a **Pull Request** (propose your changes to the original project).

---

## 🛠 Prerequisites
Before we start, make sure you have:
1. A computer with an active internet connection.
2. **Git** installed on your computer.  
   Helpful videos:  
   - [How to Install Git (Video 1)](https://www.youtube.com/watch?v=ON5GAXubt_4)  
   - [How to Install Git (Video 2)](https://www.youtube.com/watch?v=qkbK31dMNfM)
3. A **GitHub Account**.

## 🚀 Step‑by‑Step Guide

### Step 1: Fork the Repository
- Open the project on GitHub.
- At the top‑right corner, click the **Fork** button.  
✅ You now have your own copy of the project under your GitHub account!

---

### Step 2: Clone the Repository
- Click the green **Code** button and copy the link.
- Open **Git Bash** and run:
  ```bash
  git clone https://github.com/YourUsername/good-first-issue.git
